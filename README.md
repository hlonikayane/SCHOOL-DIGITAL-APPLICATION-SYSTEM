# Lenyora Primary School Digital Application System

A digital school application system developed using:

- Flutter
- ASP.NET Core
- Supabase

## Project Status

Phase 2 – System Architecture and Design

## System Architecture

The system consists of:

### Flutter Mobile Application
Used by Parents/Guardians to:
- Register and log in
- View announcements
- View subjects by grade
- Complete learner applications
- Upload required documents
- Submit applications
- Track application status

### ASP.NET Core Web Application
Used by School Administrators to:
- Log in
- Manage announcements
- Manage subjects
- View applications
- Search applications
- Filter applications
- Review applications
- Approve applications
- Reject applications
- Add application notes
- View dashboard information

### Supabase Backend

Supabase provides:
- Authentication
- PostgreSQL database
- Row Level Security
- Storage
- Realtime services
