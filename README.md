# Lenyora Primary School Digital Application System

A digital school application system developed using:

- Flutter
- ASP.NET Core
- Supabase

## Project Status

PHASE 3 — SYSTEM DEVELOPMENT, IMPLEMENTATION AND FINAL DEMONSTRATION


The system consists of:

### Flutter Mobile Application
Used by Parents/Guardians to:
- Register and log in
- Verify email
- View announcements
- View subjects by grade
- Complete learner applications
- Upload required documents
- Submit applications
- Track application status
- View admission slip

### ASP.NET Core Web Application
Used by School Administrators to:
- Log in
- Manage announcements
- Manage subjects
- View applications
- View documents
- Search applications
- Filter applications
- Review applications
- Approve applications
- Reject applications
- Add application notes
- View dashboard information
- View admission slip
- Can view settings and change the system theme

### Supabase Backend

Supabase provides:
- Authentication
- PostgreSQL database
- Row Level Security
- Storage
- Realtime services
