# SCHOOL-DIGITAL-APPLICATION-SYSTEM
A SCHOOL DIGITAL APPLICATION SYSTEM developed using Flutter, ASP.NET Core and Supabase.

## Project Description

The School Digital Application System is a digital solution designed to improve the school application process.

The system will allow applicants to submit school applications digitally and provide administrators with tools to manage, review and track applications more efficiently.

The system aims to reduce manual paperwork, improve accessibility, minimise errors and make the application process easier for both applicants and school administrators.

## Technologies

- Flutter
- ASP.NET Core
- Supabase
